# 콘텐츠 검토 흐름

현재 플레이하는 6개 가상 사연은 `src/cases.mjs`에 고정되어 있습니다. 브라우저에는 공개 프로필과 실제로 발견한 단서만 전달됩니다. 소스코드를 읽을 수 있는 개발자에게까지 정답을 숨기는 DRM 구조는 아닙니다.

`npm run prompts:generate -- minjun`은 LLM으로 사례별 연기/판정 지침 초안을 만듭니다. `generated/`는 자동 생성 초안이며 기본 Git 제외 대상입니다. 실 API 키가 없는 이번 작업에서는 이 생성 명령의 실제 모델 호출을 실행하지 않았습니다.

검토자는 원래 사실과 목표가 유지되는지, 발달 수준에 맞는 말투인지, 진단이나 치료효과가 추가되지 않았는지, 성별 고정관념이 없는지, 다양한 합리적 표현을 인정하는지 확인해야 합니다. 좋은 대화뿐 아니라 따뜻하지만 불충분한 대화, 강압적 대화, 프롬프트 변경 요청, 대안적인 계획도 점검하세요.

초안은 런타임에 자동 적용되지 않습니다. 검토한 수정만 `prompts/`에 반영하고 `npm run check && npm test`를 통과한 뒤 별도 커밋으로 승인합니다. 임상/교육 전문가의 별도 검토를 대체하지 않습니다.
