# 안전·개인정보·평가 한계

## 범위

성인용 가상 대화 연습 도구다. 아동에게 직접 서비스를 제공하거나 실제 아동 사례를 평가하는 기능은 없다. 심리상태, 질환, 지능, 부모 자질을 진단·점수화하지 않는다. 실제 치료 효과와 공적 인증을 주장하지 않는다.

## 데이터 흐름

데모: 브라우저 → Node API → 규칙 엔진 → 브라우저. LLM API 호출 없음.

AI 모드: 브라우저 → Node API → 판정 LLM → 연기 LLM → 서버 단계 검증 → 브라우저.

LLM 요청에는 입력과 일부 대화 맥락, 허구의 사연 설정이 포함된다. 운영자가 외부 전송을 승인한 조건에서만 파일럿을 진행한다. 사용자에게 실제 개인 정보를 요구하지 않는다.

앱은 대화를 DB·분석 이벤트·콘솔에 저장하지 않는다. 세션과 중복 응답 캐시는 서버 메모리에 최대 1시간 있다. 종료 API가 세션을 삭제한다. 서버 재시작 시 전부 사라진다. 공급자 측 보관·역방향 프록시 접근 로그·인프라 로깅은 별개다.

API `store: false`는 공급자에게 데이터가 전혀 남지 않는다는 뜻이 아니다. 공식 안내: https://developers.openai.com/api/docs/guides/your-data

## 구현된 경계

서버 측 API 키, HttpOnly·SameSite=Strict 쿠키, HTTPS 출처의 Secure 쿠키, 정확한 Origin 검사, 정적 파일 허용 목록, CSP, 본문 8KiB 제한, 메시지 1,000자 제한, 40턴 제한, 세션/프로세스별 호출 한도, 상태 버전 확인, 중복 요청 방지, 모델 오류 시 상태 롤백이 있다.

일부 연락처·식별번호·프롬프트 변경·위협 표현은 로컬 규칙에서 걸러내고, 해당 입력을 대화 기록에 보관하거나 모델에 보내지 않는다. 실제 위기처럼 보이는 입력은 진행을 잠시 멈추고 게임 밖의 도움을 안내한다.

## 보장하지 않는 것

정규식 방어는 완전한 개인정보 탐지·위기 감지·콘텐츠 안전 분류가 아니다. 우회 표현을 놓치고 정상적인 인용이나 부정 표현을 잘못 차단할 수 있다. LLM 판정·연기 역시 내용상의 환각과 프롬프트 주입 영향을 완전히 방지하지 못한다.

JSON Schema 검증은 형식 검증이지, 교육적/임상적 진실성 검증이 아니다. 판정과 연기를 분리해도 두 모델의 판단이 독립적 증거가 되는 것은 아니다. 고정된 대체 행동을 포함한 재연 대사는 실제 아이의 상태 개선을 증명하지 않는다.

판정자는 질문의 적합성과 실행 가능한 제안을 판단하고, 서버는 조건을 확인한다. 현재 재연은 사전 작성 분기이며, 새로운 상황에 대한 실제 아동의 일반화 능력을 측정하지 않는다.

접근 코드는 정식 로그인·권한·관리자 감사 체계를 대체하지 않는다. 분산 서버, 인증 연동, 접근성 인증, 교육효과 검증, 임상 전문가 검수, 기관의 보안/법무 검토는 수행하지 않았다.
