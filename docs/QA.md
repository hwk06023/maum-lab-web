## 브라우저 확인

브라우저의 네트워크 이동이 환경 정책으로 차단되어, 정책을 변경하지 않고 오프라인 Chromium 렌더링으로 UI를 확인했다. 대화 요청만 좁게 정의한 로컬 API 브리지로 별도 실행한 Node 서버에 전달했다.

확인한 항목: 1440px에서 6개 카드, Lv.2 필터 후 2개 카드, 시작 안내, 민준의 3개 단서, 계획 합의, 지원 버튼, 두 재연, 결과 화면. pageerror 0건. 390px 모바일 홈의 가로 넘침 없음.

이는 공개 URL의 실제 HTTP 브라우저 E2E·TLS 검증이 아니다. 별도 Node HTTP 테스트가 Origin·쿠키·헤더를 검증한다. 모바일의 모든 사연 전체 플레이, 스크린리더, 실제 사용자 접근성 평가, 다른 브라우저 엔진은 미검증이다.

## 아직 검증하지 않은 것

실제 LLM 계정 호출, 프롬프트 초안의 실생성, 외부 배포, DNS, HTTPS 인증서, Docker 빌드, GitHub 원격 생성/Actions 실행, 부하·분산·침투 시험, 교육/상담의 타당성과 실제 효과.

모델 없는 데모가 작동하는 것과 실제 LLM 모드가 해당 계정·모델에서 올바르게 동작하는 것은 별개다. 실모드로 시연하기 전에 별도 API 키로 접근 권한·지연·비용·한국어 의미 판정을 검증해야 한다.
