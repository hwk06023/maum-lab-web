# 제품 방향 · 마음연습실

## 네이밍 결정안

서비스명은 **마음연습실**, 영문 프로젝트 표기는 **Maum Lab**, 저장소는 `maum-lab`, 제안 서브도메인은 `maum.hyunwoo.ai`.

`maum`은 '마음'을 떠올리기 쉽고 짧으며, 현재의 가상 아동 대화에서 교사·보호자의 연습 콘텐츠로 넓히기에도 어울린다는 기획 판단이다. 상표·상호 충돌 검토를 완료했다는 의미는 아니며 DNS의 기존 사용도 확인하지 않았다.

방송명이나 특정 실존 전문가를 외부 브랜드로 쓰지 않는다. '교화 성공' 대신 관찰 가능한 가상 연습의 변화와 지원을 보여준다. 정부기관을 연상시키는 공식 인증·로고는 승인 없이 추가하지 않는다. 기관 업무와 관련되었다는 요청 배경과 공식 서비스 여부를 구분한다.

## 사용자와 경험

초기 대상은 교사·보호자·예비교사 등 성인이다. 아이가 직접 상담을 받는 서비스가 아니다.

사용자가 대화로 확인한 사실을 모으고, 아이와 구체적인 방법을 합의하고, 주변 지원을 확정한 뒤 다른 장면에서도 방법을 적용하는 경험을 만든다. 초기 참고 아이디어는 사용자가 제시한 예/아니오 추리 게임의 '질문–정보 발견–가설–판정' 구조이며, 해당 게임의 코드·사연·이미지를 복사하지 않았다.

## 게임 상태

`listen → plan → rehearse → transfer → complete`

- listen: 세 단서와 대화 근거를 모은다.
- plan: 구체적인 아이의 행동 + 주변 지원 + 아이의 참여 의사를 확인한다.
- 지원 확인: 미리 작성한 보호자/교사 역할 카드로 **가상 시나리오 안에서** 지원을 확정한다.
- rehearse: 처음의 상황에 합의한 도움을 적용한다.
- transfer: 변형된 상황에 적용한다.
- complete: 실제 상담 효과가 아니라 시뮬레이션 진행 조건을 충족했다는 기록을 보여준다.

초기 데모는 각 캐릭터당 세 단서와 두 재연 장면으로 범위를 통일했다. 난이도별 콘텐츠 복잡도와 질문 도우미의 기본 노출은 다르지만, 현재의 턴 한도·필수 단서 개수는 같다. 난이도 보정이나 학습효과 검증을 완료한 것은 아니다.

## 다음 검토 항목

자연어 정답 인정 범위를 넓히는 의미 평가, 가설 노트의 수동 작성, 보호자·교사 관찰 자료의 별도 열람, 더 다양한 부분 성공 결과, 접근성·가독성 검토, 여러 연령대와 상황 확대는 후속 범위다. 실제 위험·학대·위기 사례는 게임 콘텐츠를 복잡하게 만들기 위한 소재로 자동 생성하지 않는다.

현재의 대화·재연 반응은 고정 설정과 생성 규칙에 기반한 허구다. 실제 아동 행동을 예측하는 모델이 아니다. 행동의 맥락·공동 문제해결·주변 지원을 고려한다는 설계 원칙만으로 임상적 효과를 주장할 수 없다.
